# Chrome Web Store Listing — Markup

## Extension Name (30 chars max)

**Markup: Markdown Editor**

## Short Description (132 chars max)

A lightweight markdown editor with live preview, themes & HTML export. Edit READMEs, textarea content, and quick notes anywhere.

## Detailed Description (1000 chars max)

Markup is a privacy-first markdown editor that lives inside Chrome. No accounts. No servers. No tracking. Just open the popup or side panel and start writing.

**Features:**
- Full markdown editor with live preview in the side panel
- Standalone editor tab for focused writing
- Three built-in themes: Dark, Minimal, and Editorial
- Export documents as beautiful, self-contained HTML files
- Copy HTML directly to clipboard
- Quick notes from the toolbar popup — saved locally
- GitHub integration — "Edit in Markup" button appears on every README
- Textarea helper — click the floating icon on any large textarea to edit its content
- Context menu — right-click selected text to open it in Markup
- .md link intercept — Shift+click any markdown link to open it
- Offline-first — all data stored in chrome.storage.local
- Optional custom backend URL for self-hosted sync

**Keyboard shortcuts:**
- Ctrl+Shift+M (Cmd+Shift+M on Mac) — open popup
- Ctrl+Shift+U (Cmd+Shift+U on Mac) — open side panel
- Ctrl+Enter — save quick note

Perfect for developers, writers, and anyone who lives in the browser.

## Privacy Practices

Markup is built with privacy as a core principle.

- **No data collection:** The extension does not collect, transmit, or share any user data with the developer or third parties.
- **Local-only storage:** All notes, documents, themes, and settings are stored exclusively in chrome.storage.local on your device.
- **No network calls:** The extension functions entirely offline. No analytics, no telemetry, no external APIs.
- **Optional backend:** Users may optionally configure a custom backend URL for self-hosted sync. This is entirely user-controlled and disabled by default.
- **No permissions abuse:** The extension requests only the minimum permissions necessary: storage, sidePanel, contextMenus, activeTab, and GitHub host access for README button injection.
