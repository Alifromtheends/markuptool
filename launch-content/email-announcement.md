# Email Announcement

---

## Subject Lines (5 Options)

**Option 1 — Direct & Curious:**
> I built a markdown editor with zero dependencies. Here's the link.

**Option 2 — Benefit-Focused:**
> Write markdown. Export a single HTML file. No server required.

**Option 3 — Story-Driven:**
> Why I built my own markdown editor (and why it has no dependencies)

**Option 4 — Short & Punchy:**
> Markup is live — privacy-first markdown to single-file HTML

**Option 5 — Question Hook:**
> What if your markdown editor didn't need a server, an account, or a build step?

**Recommended:** Option 1 for tech-savvy lists, Option 4 for general audiences, Option 5 for LinkedIn-style professional contacts.

---

## Body Copy (Use with any subject line)

Hey [First Name],

Quick one — I shipped a new tool this week and wanted to share it with you first.

**Markup** is a browser-based markdown editor with one standout feature: it exports to a single, self-contained HTML file.

No build step. No dependencies. No server. No tracking. The exported file opens in any browser, works offline, and contains zero external requests.

**What you can do with it:**
- Write docs or notes and export them as portable files
- Build one-page portfolios or landing pages
- Create documentation you can email to clients
- Archive writing in a format that'll still render in 2035

The editor itself is a single HTML file too — save it locally and use it without ever touching a server.

**Try it here:** https://alifromtheends.github.io/markuptool/
**Source code:** https://github.com/Alifromtheends/markuptool (MIT)

It's completely free and open source. If it solves a problem for you, I'd love to hear how you're using it. If it doesn't, tell me what's missing — I actually read replies.

Cheers,
Ali

## Sending Checklist

- [ ] Segment list: prioritize developers, writers, and privacy-conscious contacts
- [ ] Send Tuesday or Wednesday, 10:00 AM recipient's local time
- [ ] Use plain text for close contacts, HTML for broader lists
- [ ] A/B test subject lines with a 20% sample if your list is >500
- [ ] Set up reply tracking — replies are more valuable than opens
- [ ] Follow up with non-openers in 5–7 days with a shorter version
