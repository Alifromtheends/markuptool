## About the Product

**Markup** is a privacy-first markdown editor that exports to single-file, self-contained HTML websites. Open it in a browser, write markdown with live preview, pick a theme, and export a standalone `.html` file that works offline in any browser — today or decades from now.

**The core idea:** Writing and publishing on the web shouldn't require accounts, build pipelines, or cloud dependencies. Markup is the anti-platform: it gives you a file, then gets out of your way.

**What makes it different:**
- **Single-file export** — CSS, fonts, and rendered content inlined into one portable HTML file
- **Zero dependencies** — the editor is one HTML file. No frameworks. No build step. No `npm install`.
- **Privacy by absence** — no tracking, no cookies, no external requests, no accounts
- **Future-proof** — exported files rely only on web standards. They'll render as long as browsers exist.

## Coverage Guidelines

**What we love to see mentioned:**
- The single-file export angle (it's the core differentiator)
- Zero dependencies / no build step
- Privacy-first by design
- The fact that the editor itself is a single HTML file
- Open source (MIT) and free

**What to avoid:**
- Calling it a "static site generator" — it's simpler than that
- Implying cloud sync or collaboration features exist
- Suggesting it's an "alternative to Notion" — different category entirely
- Exaggerating the feature set (it's intentionally minimal)

**Suggested headline formats:**
- "This Markdown Editor Exports to a Single HTML File — No Dependencies Required"
- "Markup: A Privacy-First Markdown Tool That Needs No Server, No Build, No Account"
- "One File, Zero Dependencies: Inside Markup, the Anti-Platform Markdown Editor"
