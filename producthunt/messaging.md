# Markup — Key Messaging Framework

---

## One-Liner

> **The markdown editor that ships a website in one file.**

---

## Value Propositions (3)

### 1. Zero-Friction Creation
No accounts. No installs. No build steps. Open the file, write markdown, export a complete website. Markup removes every barrier between idea and published page.

### 2. Total Privacy
Your data never leaves your browser. No cloud sync, no tracking, no server. localStorage only. Perfect for sensitive docs, offline work, and privacy-conscious creators.

### 3. Theme-First Design
Seven handcrafted themes — from terminal-green Matrix to editorial Paper — let you publish with visual identity, not just raw markdown. Every export looks intentional.

## Differentiators vs Competitors

### vs Notion
| Notion | Markup |
|--------|--------|
| Cloud-only, requires account | Works offline, zero signup |
| Bloated export (blobs + JSON) | Single self-contained HTML file |
| Limited custom themes | 7 distinct, premium themes |
| Tracks everything you type | Zero telemetry |

### vs Typora
| Typora | Markup |
|--------|--------|
| Desktop app only | Runs in any browser |
| Paid ($14.99) | Completely free |
| Proprietary | Open source |
| No live theme switching | Instant theme preview |

### vs Obsidian
| Obsidian | Markup |
|----------|--------|
| Vault-centric, file management | One file, zero config |
| Plugin ecosystem (complexity) | Intentionally minimal |
| Sync is paid | No sync needed — one file |
| Geared for knowledge bases | Geared for publishing |

## Target Audience

### Primary
- **Indie developers & technical writers** who want to publish docs, READMEs, or blog posts without setting up a site generator
- **Privacy-focused users** who refuse cloud-based tools
- **Designers & creatives** who want beautiful exports without touching CSS

### Secondary
- **Students & researchers** taking markdown notes that need to become shareable pages
- **Digital nomads / offline workers** who need a fully capable editor without internet
- **Minimalists** who reject subscription software

### Persona: "Offline Ali"
- Writes on planes, in cafes with bad WiFi
- Values privacy, refuses Google Docs for personal writing
- Wants to publish a landing page or doc without learning 11ty/Hugo
- Appreciates good typography but doesn't want to write CSS
