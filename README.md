# Markup

A privacy-first markdown editor that exports beautiful, single-file websites.

**[Try it live →](https://alifromtheends.github.io/markuptool/)**

---

## What it does

1. **Write** markdown in the left pane
2. **Preview** live in the right pane
3. **Switch** between 3 themes (Dark, Minimal, Editorial)
4. **Export** as a standalone `index.html` — zero dependencies, deploy anywhere
5. **Copy** HTML directly to clipboard for pasting into CMS, email, or code

## Why it exists

Most markdown editors either:
- Require accounts and store your data on their servers
- Export bloated files with 50 dependencies
- Look like they were designed in 2012

Markup is the opposite. **One file. Zero servers. Your data stays in your browser.**

## Features

- ✨ Live preview as you type
- 🎨 3 built-in themes (Dark Hacker, Minimal Light, Editorial Serif)
- 📦 Export as single HTML file
- 📋 Copy HTML to clipboard
- 💾 Auto-save to localStorage
- 📱 Mobile responsive
- 🖥️ Resizable split pane
- 🔒 Zero tracking, zero cookies, zero API calls

## Markdown Support

- Headers (H1–H6)
- Bold, italic, strikethrough
- Links and images
- Code blocks with language tags
- Blockquotes
- Tables
- Task lists / checkboxes
- Horizontal rules

## How to use

**Online:**
Open [https://alifromtheends.github.io/markuptool/](https://alifromtheends.github.io/markuptool/) and start writing.

**Offline:**
```bash
git clone https://github.com/Alifromtheends/markuptool.git
cd markuptool
open index.html
```

**Self-host:**
Drag `index.html` to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages).

## Export & Deploy

Click **Export HTML** to download a standalone file. That file is your entire website. No build step. No dependencies. Upload it anywhere.
